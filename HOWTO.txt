EGoRCL0uD — инструкция

УСТАНОВКА
Запусти "EGoRCL0uD Setup.exe", жми Next до конца.

ВХОД (нужен один раз для лайков и плейлистов)
1. Открой soundcloud.com в браузере, залогинься.
2. F12 → Network → кликни любой трек на сайте.
3. Найди запрос к api-v2.soundcloud.com, скопируй из URL значение client_id=...
4. F12 → Application → Cookies → soundcloud.com → скопируй oauth_token
5. В программе набери на клавиатуре: l o g i n
6. Вставь оба значения, жми Save.

УПРАВЛЕНИЕ
S или /         — поиск (Esc — выйти из поиска)
Enter           — искать
Q               — мои плейлисты
E               — мои лайки
Space           — пауза / продолжить
← / →           — предыдущий / следующий трек
↑ / ↓           — громкость
V               — показать/скрыть полоску перемотки
ЛКМ по треку    — играть (по играющему — пауза)
ПКМ по треку    — меню: Like / Add to Playlist
ЛКМ по верхней
серой полоске   — перетащить окно
Alt+F4          — закрыть
