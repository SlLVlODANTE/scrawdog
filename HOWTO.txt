scrawdog — инструкция

УСТАНОВКА
Запусти "scrawdog Setup.exe", жми Next до конца.

ВХОД (нужен один раз для лайков и плейлистов)
1. Открой soundcloud.com в браузере, залогинься.
2. F12 → Application → Cookies → soundcloud.com → скопируй oauth_token.
3. В программе набери на клавиатуре: l o g i n
4. Вставь токен, жми Save.

УПРАВЛЕНИЕ
S или /         — поиск (Esc — выйти из поиска)
Enter           — искать
Q               — мои плейлисты
E               — мои лайки
Space           — пауза / продолжить
← / →           — предыдущий / следующий трек
↑ / ↓           — громкость
V               — показать/скрыть полоску перемотки
T               — окно выбора темы
ЛКМ по треку    — играть (по играющему — пауза)
ЛКМ по нику    — открыть страницу артиста (только его треки)
ПКМ по треку    — меню: Like / Add to Playlist
ЛКМ по верхней
серой полоске   — перетащить окно
Alt+F4          — закрыть
